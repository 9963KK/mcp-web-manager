使用 JSON 添加 MCP 服务

支持 通用 MCP 配置 与 内部批量/单对象 三种格式（会自动识别）：

1) 通用：Claude Desktop / mcp-proxy 的 mcpServers

{
  "mcpServers": {
    "fetch": {
      "enabled": true,
      "command": "uvx",
      "args": ["mcp-server-fetch"],
      "env": { "API_KEY": "xxxxx" },
      "cwd": "/root"
    }
  }
}

2) 标准批量：services 数组

{
  "services": [
    { "name": "a", "command": "uvx", "args": ["mcp-server-a"] },
    { "name": "b", "command": "uvx", "args": ["mcp-server-b"], "env_vars": {"FLAG": "1"} }
  ]
}

3) 单对象：等同创建一个服务

{
  "name": "fetch",
  "description": "示例 stdio 服务",
  "command": "uvx",
  "args": ["mcp-server-fetch", "--verbose"],
  "env_vars": {"API_KEY": "xxxxx"},
  "working_directory": "/root",
  "streamhttp_host": "127.0.0.1",
  "auto_restart": true,
  "timeout": 60
}
